# Skolta · maqueta para eventos

Maqueta ilustrativa de Skolta, la escolta digital del transporte pesado. Muestra el problema que resuelve y una demo guiada: rutas compatibles con las medidas del vehículo, alertas preventivas, botón de pánico y panel de la empresa.

- Ábrala en el teléfono y use «Agregar a pantalla de inicio»: después funciona sin internet.
- `?vitrina` la hace avanzar sola; `?paso=N` abre directo en la pantalla N.

Mapa, nombres y datos son simulados.
